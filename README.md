## ✨ Features

- **Signature Event Horizon Portal:** Animated cosmic black hole accretion disk with a continuous horizontal laser beam and atmospheric lighting.
- **Technology Radar Orbit:** Concentric orbital radar coordinate system with floating glass cards for React, JavaScript, TypeScript, Next.js, AWS, Python, GitHub, Vite, HTML5, and CSS3.
- **Interactive 3D Holographic Photo Portal:**
  - Automatically unfolds in 3D perspective when visiting the About Me section.
  - Smoothly folds and closes back into cosmic space when leaving the section.
  - Interactive 3D mouse parallax tilt tracking cursor movements.
  - Cybernetic scanning line, HUD corner brackets, and live status badge.
- **Skills Matrix:** Categorized into Frontend Engineering, Backend & Languages, and Workflow & Cloud tooling.
- **Featured Projects:** High-fidelity project cards with interactive preview mockups, tech tags, and live demo video/app links.
- **Education Timeline:** Clean vertical glowing timeline highlighting academic milestones at Joy University and Montessori Elite E.M School.
- **Responsive Design:** Fully optimized for desktops, laptops, tablets, and mobile smartphones.
- **Pure Web Standards:** Built using pure semantic HTML5 and CSS3 (no external frameworks like React, Bootstrap, or Tailwind CSS).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, accessible landmarks, and inline SVGs.
- **CSS3:** Custom properties, CSS Grid, Flexbox, glassmorphism (`backdrop-filter`), and lightweight GPU-accelerated keyframe animations.
- **JavaScript:** Minimal vanilla JavaScript strictly for `IntersectionObserver` 3D scroll triggers and cursor tilt parallax.

## 💻 Local Setup & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gollamanogna9/Portfolio.git
   cd Portfolio
   ```

2. **Open in browser:**
   Simply double-click `index.html` to open it in Chrome, Edge, or Firefox.

3. **Or run with local server (PowerShell):**
   ```powershell
   .\server.ps1 -Port 3000
   ```
   Then visit `http://localhost:3000/`.
